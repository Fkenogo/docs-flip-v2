# 1. Purpose

This document defines the end-to-end journeys users follow when interacting with Docsflip. These journeys provide the bridge between user needs and product capabilities.

---

# 2. Journey Principles

- Every journey begins with a user goal.
- Every step should minimise friction.
- Commercial events should be transparent.
- Users should always understand their progress.
- Journeys should be consistent across user types.

---

# 3. Core Journeys

## J1 — Discover Docsflip
Learn about the platform and understand its value proposition.

## J2 — Register & Create Account
Create an individual or organisation account.

## J3 — Create Organisation
Set up an organisation workspace and invite team members.

## J4 — Upload Document
Upload a PDF and validate it for publishing.

## J5 — Preview Publication
Review the converted publication before committing to publish.

## J6 — Acquire Publishing Capacity
Obtain credits or other publishing capacity.

## J7 — Publish
Publish the document and receive a hosted digital publication.

## J8 — Share Publication
Distribute the publication via links, embeds or QR codes.

## J9 — Manage Publications
Update, archive, renew or retire publications.

## J10 — Review Insights
View publication usage and performance metrics.

# 5. Outputs

These journeys define the capabilities documented in FEA-001 and the functional requirements in REQ-001.

---

# 6. Foundational Decisions

1. Every feature must support at least one journey.
2. Every journey must support one or more user goals.
3. Journey design precedes feature specification.
