## 2. Assessment

WP-02 was defined before the Capability Framework was integrated. Its original objective — "Expand PA-001" — assumed that PA-001's domain set was correct and ready for content.

That assumption is no longer valid. PA-RP-001 identified 3 invented domains, 1 capability gap, and 5 constitutional conflicts. PA-001 must be structurally refactored before content expansion can begin.

---

## 3. Recommendation

**Supersede WP-02 and replace with a refactoring work package.**

| Action       | Detail                                                                                                                                                         |
| ------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| WP-02        | **Close — Superseded.** Archive existing WP-02 artefacts (Audit Report, Domain Matrix, Decision Agenda, Preparation Validation Report) as historical analysis. |
| New WP       | **Create WP-02R — Refactor PA-001 to CAP-001.** Execute the 3-phase migration defined in PA-RP-004.                                                            |
| New WP scope | Phase 1: Structural refactoring (9 steps). Phase 2: Domain content (6 domains). Phase 3: Relationship model (3 steps).                                         |
| Deliverable  | PA-001 v0.2, L2 Expanded, 6 CAP-aligned domains                                                                                                                |

---

## 4. Rationale

1. CAP-001 is authoritative. PA-001 must conform. Expanding an incorrect skeleton would create downstream rework.
2. The Capability Framework resolves the structural decisions that WP-02's Decision Agenda was designed to address.
3. WP-02 audit artefacts (Audit Report, Domain Matrix, Decision Agenda) remain valuable as historical analysis and can inform WP-02R Phase 1.
4. The 3-phase migration strategy (PA-RP-004) provides a clear, bounded scope for the replacement work package.
